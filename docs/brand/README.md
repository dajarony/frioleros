# Propuesta A: oso geométrico

Estado: **boceto vectorial para revisión**, no es la marca oficial ni se usa en la web publicada.

El símbolo conserva el oso polar elegido por el grupo en esta exploración, pero reduce el dibujo a silueta, ojo, hocico y una sola zona azul. El archivo `oso-geometrico-a.svg` es editable y escalable. Antes de sustituir el logo actual hay que revisar el símbolo a 32, 48 y 224 px, elegir un tratamiento para el nombre «Frioleros» y aprobarlo expresamente.

La paleta propuesta reutiliza los colores actuales: azul oscuro `#04111e`, blanco `#f7fbff` y azul hielo `#2bc1ff`. No se han creado ni publicado versiones finales, favicons o tarjetas sociales con este boceto.
