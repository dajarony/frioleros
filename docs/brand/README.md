# Identidad A: oso simplificado

Estado: **marca de uso web aprobada e integrada**. El símbolo oficial para pantalla es `public/brand/frioleros-bear-a.png`; la cabecera lo combina con el nombre «Frioleros» como texto para conservar nitidez y accesibilidad.

El símbolo conserva el oso polar elegido en esta exploración, pero reduce el dibujo a silueta, ojo, hocico y una sola zona azul. `oso-simplificado-a-referencia.png` es la fuente visual generada a 1254 × 1254 px con transparencia. De ella se derivan el símbolo web de 512 px y el icono de 192 px. `oso-a-prueba-tamanos.png` documenta la revisión en fondos oscuro y claro a 32, 48 y 224 px.

`oso-geometrico-a.svg` se conserva como exploración vectorial y no es el activo publicado, porque no se pudo completar su revisión visual directa. La marca web usa el PNG que sí fue inspeccionado en los tamaños de contrato. Esta referencia no se usa como prueba de prácticas ni representa un alumno real.

La paleta reutiliza los colores actuales: azul oscuro `#04111e`, blanco `#f7fbff` y azul hielo `#2bc1ff`. El mismo símbolo alimenta la cabecera, el hero, el favicon, el manifiesto y las tarjetas sociales para evitar variantes incoherentes.
