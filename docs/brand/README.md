# Propuesta A: oso geométrico

Estado: **boceto vectorial para revisión**, no es la marca oficial ni se usa en la web publicada.

El símbolo conserva el oso polar elegido en esta exploración, pero reduce el dibujo a silueta, ojo, hocico y una sola zona azul. `oso-simplificado-a-referencia.png` es una referencia visual generada a 1254 × 1254 px con transparencia. `oso-geometrico-a.svg` es el primer trazado editable de esa dirección; todavía no se ha comprobado que coincida píxel por píxel con la referencia.

Antes de sustituir el logo actual hay que revisar el SVG junto al nombre «Frioleros» a 32, 48 y 224 px, comprobar contraste sobre fondos claros y oscuros y aprobar una versión final. Esta referencia no se usa como prueba de prácticas ni representa un alumno real.

La paleta propuesta reutiliza los colores actuales: azul oscuro `#04111e`, blanco `#f7fbff` y azul hielo `#2bc1ff`. No se han creado ni publicado versiones finales, favicons o tarjetas sociales con este boceto.
